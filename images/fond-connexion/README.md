# Image de fond de connexion et d’inscription

Déposez votre image dans ce dossier sous le nom exact : `fond-connexion.webp`.

Chemin attendu depuis la racine du dépôt : `images/fond-connexion/fond-connexion.webp`.

Formats conseillés : WebP ou JPG. Si vous utilisez JPG, convertissez l’image en WebP ou modifiez aussi le chemin dans `auth-background.css`.

Pour remplacer l’image plus tard, conservez ce nom de fichier et remplacez simplement le fichier image.
